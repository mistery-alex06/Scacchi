Scacchi

Un'applicazione web di scacchi interattiva, leggera e altamente configurabile, progettata per offrire un'esperienza di gioco fluida e moderna direttamente nel browser.

Caratteristiche Principali
- Interfaccia Pulita & Moderna:** Design minimale e responsivo realizzato con HTML5 e CSS3.
- Logica di Gioco Robusta:** Gestione completa delle mosse e dello stato della partita tramite JavaScript puro.
- Configurabilità Avanzata:** File `settings.json` dedicato per gestire le impostazioni e i parametri di gioco in modo scalabile.
- Zero Dipendenze:** Funziona nativamente nel browser senza la necessità di complessi setup o build tools.

Struttura del Progetto
```text
chess_app/
├── index.html       # Entry point dell'applicazione
├── style.css        # Fogli di stile e design system
├── script.js        # Core logic e gestione della scacchiera
└── settings.json    # Configurazioni di gioco
```

Come Iniziare (Quick Start)

1. Clona la repository:
   ```bash
   git clone https://github.com/tuo-username/chess-app.git
   ```
2. Entra nella cartella del progetto:
   ```bash
   cd chess_app
   ```
3. Apri il file `index.html` direttamente nel tuo browser preferito (oppure usa un server locale come *Live Server* su VS Code per le performance ottimali).
